# Козёл

Мини-приложение для Telegram, которое считает очки в игре «Козёл» (домино).

Проект намеренно остаётся статическим: HTML, CSS и JavaScript без сборщика и runtime-зависимостей. Это позволяет публиковать приложение напрямую через GitHub Pages и не тащить фреймворк ради нескольких экранов и таблицы счёта.

## Правила подсчёта

- В партии участвуют от 2 до 4 игроков.
- Пока счёт игрока не открыт, очки отображаются «на карандаше».
- Раунд с 13 или более очками открывает счёт игрока.
- Ноль до открытия счёта сбрасывает накопленные предварительные очки.
- После открытия счёта ноль ничего не сбрасывает.
- Партия заканчивается, когда игрок набирает 101 очко или больше.

## Telegram Mini App

В `index.html` подключён официальный Telegram Web App SDK. Приложение:

- сообщает Telegram о готовности через `WebApp.ready()`;
- разворачивается на доступную высоту через `WebApp.expand()`;
- использует Telegram theme CSS variables;
- использует haptic feedback и нативные confirm-диалоги, когда API доступен;
- корректно работает как обычная веб-страница вне Telegram.

Текущая GitHub Pages публикация: `https://sergio-lykov.github.io/goat/`.

## Локальный запуск

Из корня проекта запустить любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## Проверки

Нужен Node.js 22+.

```bash
npm run check
npm test
```

`npm test` использует встроенный `node:test`, поэтому устанавливать зависимости не требуется.

## CI

GitHub Actions запускает синтаксическую проверку JavaScript и тесты на каждый `push` и `pull_request`.
